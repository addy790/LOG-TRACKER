# Log Tracker
A lightweight, offline-first progress tracking dashboard.

# Overview

A single-file web application for tracking daily tasks, subject progress, and performance metrics 
entirely offline. No backend, no accounts, no setup friction.

# Features

Daily Dashboard — Time-blocked schedule with quick check-in

Progress Tracker — Subject-wise completion and weak-area flags

Question Log — Attempt tracking with pass/fail history

Test Logger — Score tracking with trend visualization

Error Archive — Mistake logging with review mode

Calendar Heatmap — Visual discipline tracker

Data Portability — Export/import everything as JSON

# Quick Start

bash
git clone https://github.com/addy790/LOG-TRACKER.git

cd LOG-TRACKER

# Open index.html in any browser

Or simply drag index.html into your browser. No server required.

# Tech Stack

| Layer    | Technology                      |
| -------- | ------------------------------- |
| Frontend | HTML5, CSS3, Vanilla JavaScript |
| Storage  | Browser localStorage            |
| Charts   | Chart.js (CDN)                  |
| Build    | None — zero dependencies        |


# Usage

Open index.html
Your data persists automatically in the browser
Use the sidebar to navigate between views
Export your data anytime via Settings → Export JSON
